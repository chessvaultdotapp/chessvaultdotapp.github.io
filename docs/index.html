What is Chessvault?

Chessvault is an early-stage chess desktop application. It currently lets you play both sides on an interactive board and review the game move by move.

Current availability

Chessvault is under active development and has no stable release yet. Development previews are available for Linux x86_64. Windows and macOS support is planned; mobile releases are not currently being considered.

Chessvault is not yet a complete chess platform. Draw rules other than stalemate are not currently adjudicated.

Try Chessvault

Visit the GitHub releases page to try a Linux development preview. Previews may contain bugs or incomplete features.
